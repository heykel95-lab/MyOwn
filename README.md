# Modular Master Thesis Structure

Compile the thesis with:

```bash
pdflatex Thesis.tex
bibtex Thesis
pdflatex Thesis.tex
pdflatex Thesis.tex
```

or run:

```bash
make
```

Important file for personal data:

```text
config/commands.tex
```

Replace all placeholders before submission:
- birth date/place
- study group
- second supervisor
- issue date
- submission date
