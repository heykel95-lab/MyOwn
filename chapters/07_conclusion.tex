\chapter{Conclusion and Future Work}
\label{ch:conclusion}

\section{Summary of Results}
\label{sec:summary}

This thesis developed and evaluated a Cartesian impedance controller
for the Franka Emika Panda, a 7-\abbr{DOF} collaborative manipulator.
The work covered the complete pipeline from hardware commissioning to
experimental evaluation, fulfilling all objectives stated in the thesis
registration.

The key contributions are as follows:

\begin{itemize}
  \item \textbf{System setup (Objective~2):} The workstation, real-time
        Ubuntu kernel, network connection, Franka Desk and \abbr{FCI} access,
        libfranka installation, and C++ build environment were
        successfully configured and verified.
        A deterministic 1\,ms control cycle was confirmed with
        \texttt{cyclictest}.
  \item \textbf{Software structure (Objective~3):} A modular C++
        implementation was developed, separating state acquisition,
        model access, and control logic into clearly defined layers.
        All source files are commented and reproducible on the same
        hardware/software stack.
  \item \textbf{Mathematical foundation (Objective~1, 4):}
        The controlled variable was formulated as the full end-effector
        pose $\mathbf{T}_e\in \SE$.
        The pose error $\mathbf{T}_d^{-1}\mathbf{T}_e$ yields both
        translational and rotational sub-errors from a single matrix
        product.
        Stiffness and damping matrices were derived as full \abbr{SPD} matrices
        via eigendecomposition and dyadic sums, valid for arbitrarily
        oriented task surfaces.
  \item \textbf{Stability (Objective~4):} A Lyapunov argument formally
        proves asymptotic stability for any \abbr{SPD} stiffness and damping
        matrices, including the full off-diagonal matrices arising from
        the virtual wall task.
  \item \textbf{Experimental evaluation (Objective~4):} Three experiments
        confirmed correct controller behaviour:
        the virtual wall constraint — tilt-to-contact behaviour (compliant interaction),
        stiffness variation (tracking behaviour and steady-state error),
        and configuration dependence (torque distribution across joints).
\end{itemize}

\section{Limitations}
\label{sec:limitations}

The following limitations of the present work should be noted:

\begin{itemize}
  \item \textbf{No external force sensing:} The controller relies on
        the Jacobian transpose mapping to generate compliant behaviour.
        True force measurement (e.g.\ via a wrist-mounted \abbr{FT} sensor)
        would allow direct compensation of contact forces and improve
        accuracy under external loads.
  \item \textbf{Gravity and Coriolis from the robot model:} The
        compensation terms $\bm{\tau}_g$ and $\bm{\tau}_c$ are computed
        by the libfranka model, which is based on the nominal robot
        parameters.
        Any payload attached to the flange would degrade compensation
        accuracy.
  \item \textbf{Simplified damping at low stiffness:} The critical
        damping rule $\mathbf{D}_p = 2\mathbf{K}_p^{1/2}$ was derived
        for a linear time-invariant system.
        At very low stiffness ($k < 20\,\mathrm{N/m}$), joint-level
        Coulomb friction introduces a dead-band that the linear model
        does not capture.
  \item \textbf{Orientation error singularity at $\phi = \pi$:}
        The axis-angle extraction is numerically undefined at
        180-degree orientation error.
        The special-case branch implemented handles this gracefully but
        has not been tested experimentally near this boundary.
\end{itemize}

\section{Future Work}
\label{sec:future}

The following extensions are identified as promising directions for
future work:

\begin{itemize}
  \item \textbf{Null-space control:} The one-dimensional null space of
        the 7-\abbr{DOF} Panda can be exploited to simultaneously optimise a
        secondary objective (joint-limit avoidance, preferred
        configuration) without disturbing the Cartesian task.
  \item \textbf{Adaptive impedance:} The stiffness and damping matrices
        could be adapted online based on estimated contact forces,
        enabling variable-compliance behaviour during task execution.
  \item \textbf{Orientation impedance validation:} The rotational part
        of the impedance law was derived but not independently validated
        due to experimental time constraints.
        A dedicated experiment applying pure torques about the
        end-effector axes would complete the evaluation.
  \item \textbf{Tilted virtual wall:} The experiments used an
        axis-aligned wall ($\mathbf{W}=\mathbf{I}_3$).
        Repeating the experiments with a tilted wall (full off-diagonal
        $\mathbf{K}_p$) would validate the general \abbr{SPD} matrix framework
        derived in \cref{subsec:KD_matrices}.
  \item \textbf{Model-based inertia shaping:} Replacing the unit
        virtual inertia $\mathbf{M}=\mathbf{I}_6$ with the actual
        operational-space inertia matrix would improve dynamic accuracy
        at high velocities.
\end{itemize}
