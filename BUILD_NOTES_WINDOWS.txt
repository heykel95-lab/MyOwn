Build order on Windows PowerShell:

pdflatex Thesis.tex
bibtex Thesis
pdflatex Thesis.tex
pdflatex Thesis.tex

If MiKTeX stops with a missing package dialog, install the package.
If LaTeX stops with a missing figure, make sure the file exists in the figures/ folder.

Clean LaTeX build clutter when the root folder gets crowded:

.\cleanup_build.ps1

Preview the cleanup without deleting anything:

.\cleanup_build.ps1 -WhatIf

Remove old generated preview/check PDFs too, while keeping Thesis.pdf:

.\cleanup_build.ps1 -RemoveGeneratedPdfs
