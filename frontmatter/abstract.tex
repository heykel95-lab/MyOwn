\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis investigates the design, implementation, and evaluation of a real-time Cartesian impedance controller for the Franka Emika Panda, a redundant 7-\abbr{DOF} collaborative robot. The controller is intended to produce compliant Cartesian motion while keeping the relation between pose error, impedance forces and moments, Jacobian mapping, and commanded joint torques traceable. The formulation uses stiffness and damping matrices defined in the end-effector frame and transforms them into the robot base frame.

The controller is implemented in C++ with libfranka and Eigen inside a real-time torque-control callback. The evaluation uses CSV logs from set-point, trajectory, and compliance tests together with the recorded commanded torques. In these tests, the controller converges toward the desired pose with damped transients, tracks the selected Cartesian trajectory with bounded error, shows the expected stiffness-dependent compliance, and keeps the commanded torques smooth for the evaluated parameter sets.
