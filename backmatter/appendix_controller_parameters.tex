\chapter{Controller Parameters}
\label{app:controller_parameters}
\ReviewMark{green}{The active geometry, phase gains, damping policy, timings,
null-space values, and collision settings are collected in one reproducibility
record.}

This appendix records the active controller configuration used for the reported
experiments. It is a reproducibility record for the implementation described in
\cref{ch:implementation,ch:methodology}. The controller loads
fifteen disjoint files in a fixed order:
\texttt{Run\_Settings.txt}, \texttt{safety.txt},
\texttt{Gripper\_Action.txt}, \texttt{Auto\_Damping.txt},
\texttt{Plane\_Definition.txt}, \texttt{Tool\_Orientation.txt},
\texttt{Tool\_Geometry.txt}, \texttt{Q\_Init.txt},
\texttt{Approach\_Phase.txt}, \texttt{Clearance\_Gate.txt},
\texttt{SetUp\_Phase.txt}, \texttt{Grind\_Phase.txt},
\texttt{Nullspace.txt}, \texttt{hold.txt}, and \texttt{guidance.txt}.
The values below are those recorded with each run rather than the defaults
compiled into the controller.

\section{Inertia-Scaled Damping and Centre of Compliance}

Inertia-scaled damping follows \cref{eq:implementation_cartesian_inertia,eq:implementation_inertia_scaled_damping}.
It is enabled for approach, set-up, grind, and the pause gate. The
approach factor is \(\zeta=1.9\), while set-up and grind use
\(\zeta=1.0\). The pause gate uses separate translational and rotational factors because the two
gain blocks are expressed in different frames. The configured maximum
coefficient \texttt{auto\_damping\_max} is \(400\). The configured values in
\cref{tab:active_phase_gains} provide fallback damping for the phases using
inertia-scaled damping. With
\texttt{auto\_damping\_min\_from\_manual} left at zero, those manual values act
only as that fallback and impose no lower bound on a calculated coefficient.

Standard Cartesian pose hold instead used its configured matrices directly.
All twelve reported null-space runs recorded
\texttt{hold\_auto\_damping=0}, with
\(D_p=50I_3\,\mathrm{N\,s/m}\) and
\(D_R=8I_3\,\mathrm{N\,m\,s/rad}\). The hold-damping values in
\cref{tab:active_phase_gains} are therefore active values rather than
fallbacks.

For set-up, the source damping blocks are calculated from TCP task inertia
\(\Lambda\) and then shifted to the selected centre of compliance \(p_c\). This
preserves symmetry and positive
semidefiniteness. The factor \(\zeta=1\) is the directional coefficient used by
the online damping calculation.

The coupled \(6\times6\) law is enabled only during set-up, and in Cases~C
and~E to~H. The lever was entered directly in surface coordinates through
\texttt{coupled\_use\_direct\_rc\_surface}, so
\[
r_c=R_{\mathrm{surface}}\,r_c^{S},
\qquad
r_c^{S}=[\,r_{c,t_1},\ r_{c,t_2},\ r_{c,n}\,]^\top ,
\]
with the tested components listed in \cref{tab:experimental_test_cases}. The
alternative offset-from-edge convention, in which the centre of compliance \(p_c\) is
placed relative to the contact point projected onto the surface at the
\(20\,\mathrm{mm}\) clearance hand-off, is preserved in the implementation for
archived configuration files and was not used for the reported runs. With
\texttt{coupled\_pole\_freeze\_at\_contact=1}, the references are those captured
at the hand-off, so the active \(r_c\) is constant throughout set-up.
