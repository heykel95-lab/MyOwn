\chapter{Controller Parameters}
\label{app:controller_parameters}

This appendix records the active controller configuration used for the reported
experiments. It is a reproducibility record for the implementation described in
Chapters~\ref{ch:implementation} and~\ref{ch:methodology}. The controller loads
the disjoint files
\texttt{common.txt},
\texttt{safety.txt}, \texttt{sequence.txt}, \texttt{hold.txt}, and
\texttt{guidance.txt} in that order.

\section{Automatic Damping and Centre of Compliance}

Automatic damping follows \cref{eq:software_cartesian_inertia,eq:software_auto_damping}.
It is enabled for hold, approach, set-up, grind, and the pause gate. The
approach factor is \(\zeta=1.9\), while set-up and grind use
\(\zeta=1.0\). Hold uses one fitted factor for translation and rotation. The
pause gate uses separate translational and rotational factors because the two
gain blocks are expressed in different frames. The configured maximum
coefficient is \(8000\), and the manual values in
\cref{tab:active_phase_gains} provide the fixed damping when an automatic value
is unavailable.

For set-up, the source damping blocks are calculated from TCP task inertia and
then shifted to the selected centre of compliance. This preserves symmetry and positive
semidefiniteness, but the factor \(\zeta=1\) remains a directional tuning
heuristic; it does not establish a pole-level modal damping ratio for the
coupled robot--contact system.

The coupled \(6\times6\) law is enabled only during set-up. The active centre
of compliance is selected manually and held constant:
\[
p_c=p_{\Pi,\mathrm{clr}}+
[-0.04,\ 0.08,\ 0]^\top\ \mathrm{m},
\qquad r_c=p_{\mathrm{TCP,clr}}-p_c .
\]
Here \(p_{\Pi,\mathrm{clr}}\) is the selected tool feature projected onto the
surface at the \(20\,\mathrm{mm}\) geometric clearance hand-off. The
configuration key \texttt{first\_contact\_point} denotes this geometric
reference rather than a force-detected contact edge. The TCP position is captured at the same
hand-off, so this active \(r_c\) is constant throughout set-up. With
\texttt{coupled\_pole\_manual=1}, the matrices constructed from this selected
centre of compliance are the active set-up gains.
