\section{Centre of Compliance and the Offset Adjoint}
\label{app:center_compliance}

The thesis displacement \(r_c=p_c-p_{\mathrm{TCP}}\) points from the TCP to
the selected centre of compliance. The controller source evaluates the same
transform with the internal lever
\(\ell_c=p_{\mathrm{TCP}}-p_c=-r_c\). The source identifier
\texttt{r\_c} in the following listings denotes the internal lever \(\ell_c\).
The thesis quantity \(r_c\) retains its TCP-to-centre direction. The relation
\([\ell_c]_\times=-[r_c]_\times\) makes the two displayed adjoints identical.
The same congruence is applied to stiffness and damping.

\begin{lstlisting}[style=cppstyle, language=C++, caption={Source-side compliance-centre adjoint and congruence transform.}, label={lst:app_compliance_adjoint}]
Mat3 skewMatrix(const Vec3& v) {
  Mat3 s;
  s << 0.0, -v(2),  v(1),
       v(2),  0.0, -v(0),
      -v(1),  v(0),  0.0;
  return s;
}

Mat6x6 complianceShiftMatrix(const Vec3& r_c) {
  Mat6x6 adjoint = Mat6x6::Zero();
  adjoint.block<3, 3>(0, 0) = Mat3::Identity();
  adjoint.block<3, 3>(0, 3) = skewMatrix(r_c);
  adjoint.block<3, 3>(3, 3) = Mat3::Identity();
  return adjoint;
}

Mat6x6 shiftGainToTcp(
    const Mat6x6& gain_at_center, const Vec3& r_c) {
  const Mat6x6 adjoint = complianceShiftMatrix(r_c);
  return adjoint.transpose() * gain_at_center * adjoint;
}
\end{lstlisting}

The tool-frame parameter \texttt{compliance\_center\_offset\_ee} stores the
thesis displacement \(r_c\) and is negated when the internal lever is formed.
The alternative surface-frame parameter
\texttt{r\_tcp\_from\_compliance\_center\_surface} stores \(\ell_c\)
directly. All non-zero experimental displacements used the tool-frame
definition.

\begin{lstlisting}[style=cppstyle, language=C++, caption={Selection of the decoupled or coupled spring wrench (abridged).}, label={lst:app_spring_wrench}]
const bool coupled =
    params.use_virtual_compliance_center &&
    (state == ControlState::kContactEstablishment ||
     state == ControlState::kPreGrindingHold ||
     (state == ControlState::kPoseHold &&
      params.use_contact_impedance_hold));
if (!coupled) {
  // Two independent springs. dv.tail is -omega, so the damping
  // signs match.
  Vec6 wrench;
  wrench.head<3>() = Kp * dx.head<3>() + Dp * dv.head<3>();
  wrench.tail<3>() = KR * dx.tail<3>() + DR * dv.tail<3>();
  return wrench;
}

Vec3 r_c = Vec3::Zero();
if (params.compliance_center_in_tool_frame) {
  r_c = -(R_EE * params.compliance_center_offset_ee);
} else {
  r_c = R_base_surface *
      params.r_tcp_from_compliance_center_surface;
}
const Mat6x6 K_tcp =
    shiftGainToTcp(blockDiagonal(Kp, KR), r_c);
const Mat6x6 D_tcp =
    shiftGainToTcp(blockDiagonal(Dp, DR), r_c);
return K_tcp * dx + D_tcp * dv;
\end{lstlisting}


\section{Core Control Callback}
\label{app:callback_core}

\Added{The callback acquires the state and model quantities before assembling
the torque command.}

\begin{lstlisting}[style=cppstyle, language=C++, caption={Robot-state and model quantities acquired by the torque callback.}, label={lst:callback_state_acquisition}]
Map<const Vec7> q_current(state.q.data());
Map<const Vec7> dq(state.dq.data());

const auto jacobian_array =
    model.zeroJacobian(Frame::kEndEffector, state);
Map<const Mat6x7> J(jacobian_array.data());
const Vec6 xdot = J * dq;

Map<const Mat4x4> T_EE(state.O_T_EE.data());
const Vec3 p_EE = T_EE.block<3, 1>(0, 3);
const Mat3 R_EE = T_EE.block<3, 3>(0, 0);
\end{lstlisting}

\begin{lstlisting}[style=cppstyle, language=C++, caption={Core impedance, coupled contact establishment, and torque composition.}, label={lst:implementation_pose_error}]
const Vec3 e_p = desired.p_d - p_EE;
const Vec3 e_R = applyRotationalAxisMask(
    params, orientationError(R_EE, R_d_used), R_base_surface);

Vec6 dx;
dx.head<3>() = e_p;
dx.tail<3>() = e_R;
Vec6 dv;
dv.head<3>() = desired.pdot_d - pdot;
dv.tail<3>() = -omega;

const Vec6 wrench =
    computeCartesianImpedanceWrench(
        params, state, Kp_used, Dp_used,
        KR_used, DR_used, R_base_surface,
        dx, dv, R_EE);

const Vec7 tau_nullspace = computeNullspaceTorque(
    params, model, state, J, dq);

AutomaticDisturbance disturbance;
if (state == ControlState::kPoseHold &&
    params.disturbance_auto_enabled) {
  disturbance = computeAutomaticDisturbance(
      params, model, state, disturbance_force_direction_base,
      time - state_start_time);
}

Array7 coriolis_array = model.coriolis(state);
Map<const Vec7> coriolis(coriolis_array.data());
const Vec7 tau_task = J.transpose() * wrench;
const Vec7 tau_cmd =
    tau_task + tau_nullspace + disturbance.tau + coriolis;
\end{lstlisting}

\Added{The Cartesian pose-hold study of
\mbox{\Cref{sec:nullspace_hold_study}} activates the disturbance term, whereas
its value in the surface-contact study is zero.}
