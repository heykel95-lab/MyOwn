\chapter{Recorded Experimental Data}
\label{app:recorded_data}
\ReviewMark{green}{The appendix records the signals actually used in the
evaluation and identifies the common calibrated plane used by the controller
and analysis.}

The controller stores experimental signals in a preallocated ring buffer. This
avoids file access and dynamic buffer growth inside the
\(1\,\mathrm{kHz}\) control callback. After the controller stops, the retained
rows are written in chronological order to a CSV file.

\section{Control Phases}
\ReviewMark{green}{The numeric phase values are mapped directly to their
recorded state names.}

The integer \texttt{phase} identifies the active part of the experiment:
\[
\begin{array}{c|*{6}{>{\scriptstyle}c}}
\texttt{phase} &0&1&2&3&4&5\\ \hline
\text{state}&
\texttt{approach\_orient}&
\texttt{approach\_descend}&
\texttt{set\_up}&
\texttt{grind}&
\texttt{hold}&
\texttt{manual\_guide}.
\end{array}
\]
