\chapter{Recorded Experimental Data}
\label{app:recorded_data}
\ReviewMark{green}{The appendix records the signals actually used in the
evaluation and identifies the common calibrated plane used by the controller
and analysis.}

The controller stores experimental signals in a preallocated ring buffer. This
avoids file access and dynamic buffer growth inside the
\(1\,\mathrm{kHz}\) control callback. After the controller stops, the retained
rows are written in chronological order to a CSV file.

\section{Control Phases}
\ReviewMark{green}{The numeric phase values are mapped directly to their
recorded state names.}

The integer \texttt{phase} identifies the active part of the experiment:
\[
\begin{array}{c|*{6}{>{\scriptstyle}c}}
\texttt{phase} &0&1&2&3&4&5\\ \hline
\text{state}&
\texttt{approach\_orient}&
\texttt{approach\_descend}&
\texttt{set\_up}&
\texttt{grind}&
\texttt{hold}&
\texttt{manual\_guide}.
\end{array}
\]

\section{Evaluation Quantities}
\ReviewMark{green}{The short summary routes each reported metric to its recorded
source without reintroducing unused fields.}

The pose-based alignment error \mbox{\(\theta_{\mathrm{align}}\)} was calculated
from the measured end-effector orientation, the calibrated tool normal
\mbox{\(n_{\mathrm{Tool,EE}}\)}, and the calibrated surface normal
\mbox{\(n_s\)}. Its before value was taken at the start of set-up, and its
after value from the settled set-up interval. It is retained only for the
appendix consistency check. No other plane normal was substituted in the
analysis. The main signed set-up rotation \mbox{\(\gamma_{t_i}\)} was
calculated from \mbox{\texttt{e\_R}} at the end of set-up and resolved on the surface
tangents, as \mbox{\Cref{eq:contact_induced_rotation}} and
\mbox{\Cref{eq:surface_resolved_setup_rotation}} define it.

Three markers of that same angle are written once into the set-up report
rather than into every row. All three read \mbox{\(\theta_{\mathrm{align}}\)}
and the clock alone. None feeds the phase exit or the command.
\texttt{t\_align\_fraction} is the time at which
\mbox{\(\theta_{\mathrm{align}}\)} first fell below a configured fraction of
its value at first contact. Being a relative threshold, it is reached by
conditions that end far from flat, which the absolute tolerance is not.
\texttt{deviation\_min} is the smallest \mbox{\(\theta_{\mathrm{align}}\)} the
run reached, together with the time at which it was reached. Both are defined
for every run, so a condition that never aligned still records how close it
came. \texttt{align\_status} reads \texttt{aligned} where
\mbox{\(\theta_{\mathrm{align}}\)} settled inside the tolerance for the
required hold time, and \texttt{not\_aligned} otherwise. Runs that never
settled are identified rather than discarded.

None of these determines whether the tool itself ended flat. That is
calculated afterwards from the height of the TCP above the calibrated plane,
\(n_s^\top(p_{\mathrm{EE}}-p_s)\), against the height a flatly seated tool
face would give. The classification uses the measured end-effector position
\mbox{\(p_{\mathrm{EE}}\)}, the stored surface plane, and the calibrated tool
geometry that fixes the expected flat height.
Unlike \mbox{\(\theta_{\mathrm{align}}\)}, it therefore carries no assumption
about the rotation of the tool within the gripper.

For the internally commanded hold study, redundant motion is calculated by integrating the
norm of the recorded projected joint velocity \(\dot q_{\mathrm{null}}\) over the disturbance interval.
The conditioning response is the final change in
\(\sigma_{\min}\), and Cartesian task retention is represented by the peak
position-error norm \(\lVert e_p\rVert\).
